# ELEV8 Review Experience Studio

This is an additive UX layer over the existing review email builder. It does not replace the current save/template/email-delivery backend.

The builder now has a customer-journey switcher:
1. Email
2. Landing
3. Review form
4. Save

Email preview supports click-to-edit for common sections and a quick-edit rail. The sticky save bar reuses the existing Save template and Save & make primary handlers, so the saved live template remains the same backend object currently used by the review automation.
