# Nectar theme app extension

This folder contains the Shopify theme app extension blocks for the modular Nectar platform.

Included blocks:

- `nectar-reviews.liquid` — product review widget
- `nectar-star-badge.liquid` — compact stars for product pages
- `nectar-product-card-stars.liquid` — product-card star summary
- `nectar-review-carousel.liquid` — approved review carousel
- `nectar-review-form.liquid` — signed/bulk review landing page form
- `nectar-cart-rewards.liquid` — cart rewards progress widget

The manual copy equivalents live in `Shopify-Liquid/` for stores that are not using Shopify CLI yet.
