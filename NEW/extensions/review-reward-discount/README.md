This folder is intentionally kept for the Shopify discount/free-gift work. The API now has a `discounts` module under `src/modules/discounts` and can create Shopify discount codes after a review is accepted when the discounts module and review reward settings are enabled.

When you add a Shopify Function, keep the extension-specific code here and call the API for merchant settings where needed.
