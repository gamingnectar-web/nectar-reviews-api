# Product Import Completeness Gate

Adds a strict green/orange product readiness system across batch/photo/URL review. Required coverage includes description, vendor, template, price, compare-at status, dietary supplement, package type, beverage form, existing Shopify product type, SEO, handle, weight, HS code, barcode status, all-channel policy, existing tags, brand-prefixed SKU, formula/ingredient profile, flavour family/profile, sweetness and sourness.

Brand SKU defaults: GFuel = GF, AdvancedGG = AD, Nectar = NEC, Z-Zero = XZ. Tags are filtered to existing Shopify tags. HS codes are suggested from similar existing Shopify inventory items and remain orange until merchant confirmation. Approval is blocked while completeness is not 100%.
