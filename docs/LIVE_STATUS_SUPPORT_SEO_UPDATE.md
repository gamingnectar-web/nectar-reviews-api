# Live Status, Support Modal and SEO Reviews Page Update

This build keeps reviews-first launch mode and adds:

- Product status indicators in the left navigation: green means configured/live-ready, amber means enabled but checks still need attention, beta/soon labels show unfinished products.
- Support contact settings under App Settings, used by the review-page support modal.
- Support modal order context: order ID, order date, customer name/email, items in order and affected-item selection for missing/wrong/damaged item wording.
- Email modules can use a Review page support modal link instead of a normal URL.
- Colour picker modal with a None option for module background/border fields.
- Manual review reminders use real signed review links and fall back to recent job/review context when analytics lacks an item ID.
- All Reviews SEO Page Shopify block and API endpoint for approved reviews, filters, flavour/attribute chips and JSON-LD output.

Discounts, loyalty and cart rewards remain beta/off for the reviews-only launch path.
