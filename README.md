# Nectar Reviews API - secure preserve-UI OAuth v6

This build keeps the existing review/widget/admin behaviour, keeps the secure multi-shop Shopify OAuth foundation, and adds backwards-compatible storefront endpoints for the Shopify Liquid assets.

## Important

Do not use a global `SHOPIFY_ACCESS_TOKEN` for production. Product lookup uses the per-shop OAuth token stored in MongoDB after installation.

## Required Render environment variables

```bash
APP_URL=https://nectar-reviews-api.onrender.com
MONGODB_URI=your_mongodb_uri
SHOPIFY_API_KEY=your_shopify_client_id
SHOPIFY_API_SECRET=your_shopify_client_secret
SHOPIFY_API_VERSION=2026-07
SHOPIFY_SCOPES=read_products,write_products,read_discounts,write_discounts,read_price_rules,write_price_rules,write_metaobject_definitions,write_metaobjects
EMAIL_CREDENTIAL_SECRET=long_random_secret_32_chars_or_more
ADMIN_SHARED_SECRET=temporary_dev_admin_secret
ALLOW_UNAUTHENTICATED_ADMIN=false
```

## Liquid files

Use the updated files in `Shopify-Liquid/`. The important fix is that the product widget block must load:

```text
https://nectar-reviews-api.onrender.com/review-widget.js
```

and must pass `shop.permanent_domain` and `product.id` as data attributes.

## Verification logic

Version 13 tightens verified-purchase handling so the browser can no longer mark a review as verified.

### Verified purchase sources

A review is treated as verified only when one of these server-controlled paths applies:

1. **Signed review-request link** — the token must be generated by the app, signed with the server secret, not expired, match the shop, customer email/order when provided, and include the reviewed product/variant.
2. **Merchant import** — imported reviews may preserve the merchant-supplied verified flag and are labelled as imported.
3. **Manual admin verification** — an admin can manually verify a review from Review Manager, which stores a manual verification note.

### Unverified sources

Normal storefront Write a Review submissions are always unverified, even if a crafted request tries to send `verifiedPurchase: true`.

Shopify Flow HTML links are also unverified unless they include an app-generated signed token. This is intentional because a static Flow template cannot safely contain your server signing secret.

### One-time links

Signed review tokens are hashed before storage. Once a signed token is used successfully, the hash is marked as used and the same link cannot submit another review.

### Test reviews

Test and preview review links always become `spam`/test records and can never be approved to the storefront.
