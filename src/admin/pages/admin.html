Security stance

  • No raw customer email/name/address/phone in loyalty accounts.
  • No raw Shopify customer ID stored.
  • Customer key is HMAC-SHA256(shopDomain + customer ID).
  • Webhook HMAC verification uses raw request body.
  • App proxy requests require Shopify signature and logged_in_customer_id.
  • Raw discount codes are shown only once at issue time, then stored as hashes/previews.
  • Audit log can use separate MongoDB database via MONGODB_AUDIT_URI.
